# Product Requirements Specification — Agri

## 1. Functional Requirements

### FR-01: Location & Geolocation Discovery
- **FR-01.1:** The app must request HTML5 browser geolocation upon explicit user consent `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-01.2:** If permission is denied or unavailable, the app must gracefully fallback to a manual location picker without error alerts `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-01.3:** Location precedence must strictly be: (1) Live detected geolocation, (2) User manual selection, (3) Saved local storage location `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-01.4:** The app must NEVER silently default to Bangalore or override user-chosen coordinates `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-01.5:** Location selector modal must cascade dynamically: `State` (30 states) ➔ `District` (913 districts) ➔ `Mandi` (2,643 mandis) `[DECIDED, IMPLEMENTED, VERIFIED]`.

### FR-02: Nearby Mandis (Map + List Interface)
- **FR-02.1:** Desktop view must display the interactive Map and Mandi List side-by-side in a responsive split-pane `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-02.2:** Mobile view must default to the Mandi List, providing a one-tap `Map View` toggle `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-02.3:** Map marker selection must scroll to and highlight the corresponding list card; selecting a card must pan to its map marker `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-02.4:** Filter radius must support 10 km, 25 km, 50 km, and 100 km options `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-02.5:** Search must support instant text matching across mandi name, district name, and state `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-02.6:** Mandis without GPS coordinates (2,492 mandis) must remain fully searchable in the list view, displaying an honest `Coordinates Pending` badge, and filtered out of map marker layers without crashing `[DECIDED, IMPLEMENTED, VERIFIED]`.

### FR-03: Market Profile ("My Market")
- **FR-03.1:** Dedicated URL `/market/[mandiId]` supporting commodity and variety parameters `[IMPLEMENTED, VERIFIED]`.
- **FR-03.2:** Header displaying Mandi Name, District, State, GPS coordinates or pending status `[IMPLEMENTED, VERIFIED]`.
- **FR-03.3:** Key metric cards: Latest Modal Price (₹/quintal), Min Price, Max Price, Daily Arrivals, and % change `[IMPLEMENTED, VERIFIED]`.
- **FR-03.4:** Interactive Recharts chart displaying historical modal prices and arrivals over 7, 30, or 90 days `[IMPLEMENTED, VERIFIED]`.
- **FR-03.5:** Quick actions: "View 14-Day Forecast", "Compare", and "Save Market" `[IMPLEMENTED, VERIFIED]`.

### FR-04: 14-Day Price Forecasting
- **FR-04.1:** Primary product page `/forecast` rendering a 14-day chronological price forecast `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-04.2:** Evaluation reference date strictly fixed at `2026-11-23`; forecast horizon strictly `2026-11-24` through `2026-12-07` inclusive (exactly 14 daily points) `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-04.3:** Combined chart connecting recent actual historical observations to future forecast predictions seamlessly on the reference date bridge `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-04.4:** Future predictions must show expected modal price, bounded min/max uncertainty bands, and trajectory direction (Rising, Falling, Stable) `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-04.5:** Tabular day-by-day forecast breakdown showing date, expected price, daily change %, and uncertainty range `[IMPLEMENTED, VERIFIED]`.
- **FR-04.6:** Forecast runs must be automatically persisted to PostgreSQL `forecast_runs` and `forecast_run_items` for historical auditability `[DECIDED, IMPLEMENTED, VERIFIED]`.

### FR-05: Prediction History vs Historical Prices
- **FR-05.1:** Clear conceptual separation between **Prediction History** (runs generated by ML model) and **Historical Prices** (actual transactions observed in APMC yards) `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-05.2:** Prediction History page `/prediction-history` displays previous model runs, timestamp, horizon, reference price, 7-day expected, and 14-day expected `[IMPLEMENTED, VERIFIED]`.
- **FR-05.3:** "Inspect" dialog allowing side-by-side comparison of original predicted prices against actual market prices once subsequent observations are recorded `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-05.4:** Empty states must remain authentic without fake pre-populated runs `[DECIDED, IMPLEMENTED, VERIFIED]`.

### FR-06: Cross-Market Comparison
- **FR-06.1:** Compare up to 5 mandis for the same commodity and variety at `/compare` `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-06.2:** Reject comparisons exceeding 5 mandis with HTTP 400 `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-06.3:** Render comparative multi-line charts, price spreads, and expected net differentials `[IMPLEMENTED, VERIFIED]`.

### FR-07: Saved Markets Watchlist
- **FR-07.1:** Client-side bookmarking stored in `localStorage` under `agri_saved_markets` `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-07.2:** Zero authentication required; persists across page reloads and browser sessions `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-07.3:** Saved cards provide one-click jump to market profile or forecast `[IMPLEMENTED, VERIFIED]`.

### FR-08: Internationalisation (i18n)
- **FR-08.1:** Full application language toggle supporting 6 Indian languages: English (`en`), Hindi (`hi`), Telugu (`te`), Kannada (`kn`), Marathi (`mr`), Tamil (`ta`) `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **FR-08.2:** All headings, buttons, dropdowns, empty states, chart tooltips, and badges must translate reactively `[DECIDED, IMPLEMENTED, VERIFIED]`.

## 2. Non-Functional Requirements

### NFR-01: Performance & Latency
- Paged Mandi search API response time < 50ms (achieved 10-25ms).
- Historical price queries (30-90 days) < 30ms (achieved 19ms).
- LightGBM model inference response time < 250ms (achieved ~33ms cached, ~900ms cold).
- Frontend initial page load < 1.5s on mobile 4G networks.

### NFR-02: Rate Limiting & Protection
- Public IP rate limiting enforced by sliding-window algorithm `[DECIDED, IMPLEMENTED, VERIFIED]`.
- Health and readiness endpoints exempt from rate throttling `[IMPLEMENTED, VERIFIED]`.
- Rate limit headers returned on all throttled responses: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset` `[IMPLEMENTED, VERIFIED]`.
- Exceeded quota returns HTTP 429 Too Many Requests with JSON guidance payload `[IMPLEMENTED, VERIFIED]`.

### NFR-03: Data Integrity & Ground Truth
- **Zero Coordinate Fabrication:** Never guess or hallucinate lat/lon coordinates `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **Zero Price Fabrication:** Never invent historical market transactions `[DECIDED, IMPLEMENTED, VERIFIED]`.
- **Honest Flat-Line Prevention:** Model inputs, lags, and rolling features must be computed properly so forecasts reflect genuine market dynamics `[DECIDED, IMPLEMENTED, VERIFIED]`.
